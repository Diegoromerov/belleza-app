## 6. FUENTE DEL PUERTO 5435

### Origen del puerto 5435 en la configuración:

- El puerto 5435 proviene de la variable de entorno `DB_PORT` en el archivo `/c/beauty-app/backend/.env`.
- Esta variable es leída por `runMigrations.js` cuando `DATABASE_URL` no está definida.
- No hay evidencia de que el puerto 5435 provenga de `DATABASE_URL`, configuración Sequelize directa, Docker (más allá del mapeo), o el script de migraciones de otra manera.

### Cadena de responsabilidad:

1. Archivo `.env` define `DB_PORT=5435`.
2. `runMigrations.js` lee `DB_PORT` porque `DATABASE_URL` está vacío.
3. El valor se pasa a `Sequelize` como el puerto de conexión.
4. Docker contenedor `beauty-postgres` mapea el puerto interno 5432 al puerto del host 5435.
5. Por lo tanto, la conexión a `127.0.0.1:5435` llega al contenedor Docker y luego al servidor PostgreSQL dentro del contenedor en el puerto 5432.
