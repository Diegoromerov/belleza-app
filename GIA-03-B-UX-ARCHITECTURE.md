# GIA-03-B — UX & Information Architecture Report

## 1. UBICACIÓN Y JOURNEY DE "MY GLOW"

```text
GLOWAPP (Bottom Navigation / Home / Perfil)
    │
    ▼
[ BOTÓN / CARD CANÓNICA: "MY GLOW — MI EVOLUCIÓN" ]
    │
    ▼
MY GLOW EVOLUTION DASHBOARD (Screen Principal)
    │
    ├── 1. Header de Estado y Auditoría Cero-Huella (SOUL Badge)
    ├── 2. Glow Cycle Card (Día X de 30, Métrica Objetivo, Barra de Progreso)
    ├── 3. "Plan de Hoy" (Rutina Interactiva AM / PM con Tiempos y Check-in)
    ├── 4. Productos y Servicios del Plan (GlowStore / Marketplace 1-Click)
    └── 5. Hitos y Próximo Re-Escaneo (Día 15 / Día 30)
```

## 2. JERARQUÍA DE INFORMACIÓN
1. **¿Dónde estoy y qué busco?** $\rightarrow$ Glow Cycle activo (`Skin`, `Hands`, etc.) y meta en lenguaje natural.
2. **¿Cómo voy?** $\rightarrow$ Progreso temporal y valor actual de la métrica dérmica.
3. **¿Qué hago hoy?** $\rightarrow$ Checklist interactivo AM/PM con feedback inmediato.
4. **¿Qué sigue?** $\rightarrow$ Fecha del próximo re-escaneo para medir el Delta.
