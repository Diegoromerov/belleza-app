### 2. Resilience Service (`backend/src/services/resilienceService.js`)
- Updated to import `defaultPolicy` from `./resiliencePolicy` and `logger` from `../config/logger`.
- Modified `executeWithResilience` to:
  * Use provided options or fall back to `defaultPolicy` values.
  * Accept an optional `traceId` in options for logging.
  * Enhanced logging to include:
    - Circuit breaker state changes (half-open, open, using fallback, no fallback).
    - Operation success and failure.
    - Retry attempts with delay and traceId.
    - Final outcome (fallback used or all retries exhausted).
  * Maintained backward compatibility (callers without traceId still work).
  * Preserved existing retry, timeout, circuit breaker, and fallback logic.

### 3. YouCam Client (`backend/src/services/biometric/youcam.client.js`)
- Updated to import `defaultPolicy` from `../../services/resiliencePolicy`.
- Replaced hardcoded resilience options (`retry: 3`, `retryDelay: 100`, `timeout: this.timeout`) with values from `defaultPolicy`.
- Added `circuitBreakerName: 'youcam'` to all `executeWithResilience` calls to enable circuit breaker protection.
- Note: The client's own `timeout` (15000 ms) is still used for the axios request, but the resilience timeout is now 5000 ms (from policy). This means the resilience timeout is shorter than the axios timeout; however, the resilience timeout is per attempt and the axios timeout is per request. We kept the resilience timeout as per policy (5000 ms) as a starting point; this may be adjusted in testing (F7.006-F). The axios timeout remains 15000 ms to allow the request to complete, but the resilience layer will timeout after 5000 ms and retry. This is acceptable because the resilience timeout is per attempt and we have retries.
- No fallback option is passed (the client handles fallback internally in catch blocks). This is acceptable because the resilience service's fallback is optional and the client already has fallback logic.

### 4. Gemini Client (`backend/src/services/biometric/gemini.client.js`)
- Updated similarly to YouCam client:
  * Import `defaultPolicy`.
  * Use `defaultPolicy` values for `retry`, `retryDelay`, `timeout` in `executeWithResilience` calls.
  * Added `circuitBreakerName: 'gemini'` to both `executeWithResilience` calls.
  * No fallback option passed (client has internal fallback).
