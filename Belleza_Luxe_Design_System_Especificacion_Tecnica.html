1. Resumen Ejecutivo

Este documento especifica el Design System "Belleza Luxe" para el módulo de Biometría y Belleza Premium de la aplicación Belleza App. Define un sistema de diseño de lujo/ultra-premium (referencias: Dior, La Mer, SK-II, Chanel, Guerlain) que abarca paleta de colores, tipografía, espaciado, componentes Flutter core y el overlay AR premium para escaneo biométrico con integración YouCam SDK.

El objetivo es estandarizar la experiencia visual y de interacción en el módulo de escaneo facial, cutáneo y de manos, garantizando consistencia de marca premium, accesibilidad WCAG AA y rendimiento fluido en Flutter (iOS/Android/Web).

Principales entregables:

  • Sistema de tokens de diseño (colores, tipografía, espaciado, motion) implementables en CSS y compatible con Flutter y Web.
  • Componentes core reutilizables: LuxeButton (5 variantes, micro-interacciones hápticas) y BiometricScannerOverlay (overlay AR multi-zona con YouCam SDK, partículas, haptics, ciclo de vida completo).
  • Especificación de integración YouCam SDK (4 pasos: upload slot → S3 upload → create task → poll results) con manejo de timeouts, haptics y ciclo de vida de app.

5. Componentes Principales

5.1 Design Tokens (lib/design/tokens.dart)

Fuente única de verdad para decisiones visuales. Define paletas de colores Pantone, tipografía fluida, espaciado por razón áurea, y curvas de animación motion.

5.2 LuxeButton (lib/design/components/luxe_button.dart)

Botón unificado con soporte de 5 variantes, animación háptica y control del estado de carga / deshabilitado con accesibilidad integrada mediante Semantics.

5.3 BiometricScannerOverlay

Overlay AR inmersivo que coordina el escaneo de rostro, piel y manos con validación de calidad por frame, control de timers por zona, renderizado de partículas y limpieza estricta en el método dispose().

5.4 AI Worker FastAPI (ai-worker/main.py)

Servicio en Python que procesa los resultados biométricos mediante modelos Gemini, devolviendo rutinas personalizadas y diagnósticos estructurados.

7. Riesgos Técnicos & Mitigaciones

  • Licencia YouCam SDK no disponible: Riesgo de bloquear escaneo real. Mitigación: Prototipar alternativa abierta con MediaPipe Face Mesh + Hands.
  • Contraste Dorado Insuficiente: Riesgo de incumplir accesibilidad. Mitigación: Restringir colores metálicos a bordes/iconos y usar variantes gold-on-dark.
  • JWT Expirado sin Limpieza: Causa bucles 401. Mitigación: Crear AuthInterceptor en cliente HTTP de Flutter.
