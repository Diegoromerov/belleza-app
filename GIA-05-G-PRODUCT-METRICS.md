# GIA-05-G — Product Metrics Report

## 1. SISTEMA DE MÉTRICAS DE PRODUCTO PARA GLOW IA+

| Métrica | Definición | Nivel de Medición | Objetivo / Target |
|---|---|:---:|:---:|
| **Activation Rate** | % de usuarios con cuenta que inician su primer Glow Cycle | Inmediato (V1) | $> 40\%$ |
| **Check-in Adherence** | % promedio de días con check-in completado sobre la duración del ciclo | Inmediato (V1) | $> 65\%$ |
| **Re-scan Completion Rate** | % de usuarios que realizan el re-escaneo del Día 15 / Día 30 | Inmediato (V1) | $> 50\%$ |
| **Cycle Graduation Rate** | % de ciclos activos que alcanzan estado `completed` | Inmediato (V1) | $> 35\%$ |
| **Next-Cycle Churn / Re-engagement**| % de usuarios graduados que inician un segundo Glow Cycle | V2 | $> 45\%$ |
| **Commerce Conversion Rate** | % de planes donde el usuario adquiere un SKU sugerido de GlowStore | V2 | $> 12\%$ |
| **Service Booking Rate** | % de usuarios con planes severos que reservan en Marketplace | V2 | $> 8\%$ |
