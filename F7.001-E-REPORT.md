## 3. Arquitectura de configuración
GlowApp utiliza variables de entorno cargadas mediante `dotenv` (require('dotenv').config()) en los puntos de entrada de configuración (database.js, db.js, etc.). Las variables críticas se leen directamente de `process.env` con validaciones de presencia y formato.

Flujo típico:
```
Variables de entorno (.env) 
      ↓ 
process.env.X 
      ↓ 
Validación (getJwtSecret, initializeKey, etc.) 
      ↓ 
Uso en servicios (JWT signing, database pooling, encryption, etc.)
```
