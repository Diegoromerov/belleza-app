## Reservas heredadas

De F7.001-G.1-AUDITORIA.md, las reservas documentadas que permanecen abiertas:

### R1: Dependencia de variables de entorno críticas para retención
- Riesgo: Bajo
- Impacto: Ejecución accidental de retención en producción si variables se establecen incorrectamente
- Dependencia: Variables de entorno
- Acción requerida: Revisar que las variables de entorno estén configuradas correctamente en despliegues (RETENTION_ENABLED=false por defecto en producción)

### R2: Audit trail de retención no registra IDs específicos de registros afectados
- Riesgo: Bajo
- Impacto: Limitación para investigación forense a nivel de registro
- Dependencia: Diseño de audit trail
- Acción requerida: Considerar mejorar el audit trail para incluir IDs de registros afectados si se requiere trazabilidad forense a nivel de registro (mejora futura, no bloqueo)

### R3: Falta de evidencia de RAG, Knowledge Service, Event Bus en el repositorio
- Riesgo: NV (No verificable)
- Impacto: No se puede determinar si existen o están listos para usar
- Dependencia: Ausencia de evidencia
- Acción requerida: Verificar existencia y estado de RAG, Knowledge Service y Event Bus antes de depender de ellos en F7.002

### R4: Dependencia de scheduler externo para el cron de retención
- Riesgo: Bajo
- Impacto: El cron no se ejecutará si no se configura un scheduler externo
- Dependencia: Scheduler externo
- Acción requerida: Configurar un scheduler externo (como cron del sistema, o plataforma de orquestación) para ejecutar el cron de retención en los entornos deseados

### R5: Riesgo operativo de credenciales de servicios externos mal configuradas
- Riesgo: Medio
- Impacto: Fallos en llamadas a servicios externos, posible exposición si se logran credenciales
- Dependencia: Variables de entorno de servicios externos
- Acción requerida: Verificar que las credenciales de servicios externos estén configuradas correctamente y que no se expongan en logs
