## 1. Scope
This document formalizes the architectural and technical closure of **Staff Provisioning Backend v1.0**.

The closure covers:
- DDL and physical database schema for staff invitations (`backend/migrations/074_saas_staff_invitations.sql`).
- Asynchronous invitation lifecycle, cryptographic token pipeline (SHA-256 hash storage), and invitation management endpoints (`saasStaffService.js`, `saasStaffController.js`, `saasStaffRoutes.js`).
- Dual acceptance flows: Existing Authenticated User and Canonical New User Registration.
- Multi-establishment membership and contextual role enforcement.
- Role Hierarchy & Mutability Authority Matrix (`OWNER` > `MANAGER` > `PROFESSIONAL` / `RECEPTIONIST`).
- Anti-Self-Role Mutation and Anti-Orphan Establishment Invariant rules.
- Deactivation policy (`SUSPENDED`, `ACTIVE`, `REVOKED` terminal) with data retain guarantee.
- Automated contractual test suite (`backend/tests/test_staff_provisioning_suite.js`).
