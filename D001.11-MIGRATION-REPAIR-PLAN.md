# D001.11-MIGRATION-REPAIR-PLAN.md

This document specifies the exact changes required to repair migrations 056, 057, and 058 to make them safe and idempotent for execution on both clean and existing databases, as authorized in D-001.10.

**Implementation approach** (conceptual SQL for each core table):


