Belleza Luxe Design System — Especificación Técnica

Tokens de Diseño, ThemeData & Componentes Premium

Parte 2 • Stack: Flutter 3.22+ & Dart 3.4+ • Fecha: 2026-07-30

1. Resumen Ejecutivo

Este documento constituye la segunda parte de la especificación técnica del Design System "Belleza Luxe", completando la definición de tokens de diseño iniciada en el documento anterior. Cubre:

  • Tipografía fluida con familias Didot LT Std (display) y Cormorant Garamond (body/UI), implementada vía clamp() / interpolación lineal en Flutter.
  • Sistema de espaciado basado en 4px + razón áurea (φ = 1.618), con tokens semánticos obligatorios.
  • Integración en ThemeData de Flutter (Material 3 + Cupertino hybrids) y configuración de fuentes en pubspec.yaml.
  • Fundamentos para componentes (botones, tarjetas, inputs, overlays AR) que se detallan en documentos subsiguientes.

Stack objetivo: Flutter 3.22+, Dart 3.4+, Material 3, variable fonts. Alineación estética: Dior / La Mer / SK-II / Chanel Beauty / Guerlain.

4. Tabla de Especificaciones — Espaciado

Token Valor (px) Fórmula φ Uso Semántico Obligatorio
space-0 0 — Reset, márgenes negativos controlados
space-1 4 4 × φ⁰ Micro gap: icon + label, chip interno
space-2 6 4 × φ⁰·⁵ ≈ 6.47 → 6 Inline gap, chip padding horizontal, input icon gap
space-3 8 4 × φ¹ ≈ 6.47 → 8* Unidad base: padding botón, input gap, avatar gap
space-4 12 4 × φ¹·⁵ ≈ 10.4 → 12 Card padding, list item gap, sheet padding
space-5 16 4 × φ² ≈ 16.8 → 16* Section gap, screen padding horizontal, dialog padding
space-6 24 4 × φ²·⁵ ≈ 27.1 → 24* Major section gap, page vertical rhythm
space-7 32 4 × φ³ ≈ 43.8 → 32* Hero section gap, bottom sheet handle gap
space-8 48 4 × φ³·⁵ ≈ 70.8 → 48* Pantalla completa spacing, onboarding steps

* Redondeo a múltiplos de 4px para alineación de píxel perfecta en pantallas estándar.

Regla de oro: Cero valores mágicos. Todo padding, margin, gap, borderRadius debe usar estos tokens. En Dart: LuxeSpacing.space4. En CSS: var(--luxe-space-4).

5.2 luxe_theme.dart — ThemeData Completo (Light & Dark)

// lib/design/theme/luxe_theme.dart
import 'package:flutter/material.dart';
import '../tokens/colors.dart';
import '../tokens/typography.dart';
import '../tokens/spacing.dart';
import '../tokens/motion.dart';
import '../tokens/radius.dart';
import '../tokens/shadows.dart';

ThemeData luxeLightTheme(BuildContext context) => ThemeData(
  useMaterial3: true,
  brightness: Brightness.light,
  colorScheme: ColorScheme.light(
    surface: LuxeColors.surface,                 // nude-50 #F5F0EB
    onSurface: LuxeColors.onSurface,             // nude-800 #4A382E
    onSurfaceVariant: LuxeColors.onSurfaceVariant, // nude-600 #7A5E4D
    primary: LuxeColors.primary,                 // gold-871 #C5A05A
    onPrimary: LuxeColors.onPrimary,             // nude-950 #1C1511
    primaryContainer: LuxeColors.primaryHover,   // gold-300 #E8D4A8
    onPrimaryContainer: LuxeColors.onSurface,    // nude-800
    secondary: LuxeColors.outline,               // nude-150 #DCCCC3
    onSecondary: LuxeColors.onSurface,           // nude-800
    outline: LuxeColors.outline,                 // nude-150
    outlineVariant: LuxeColors.outlineFocus,     // gold-871
    surfaceContainerHighest: LuxeColors.surfaceHover, // nude-75
    shadow: LuxeColors.onSurface.withOpacity(0.08),
  ),

  // --- Tipografía fluida ---
  textTheme: _buildTextTheme(context),

  // --- Card Theme ---
  cardTheme: CardTheme(
    elevation: 0,
    margin: EdgeInsets.zero,
    shape: RoundedRectangleBorder(
      borderRadius: BorderRadius.circular(LuxeRadius.lg), // 16px
      side: BorderSide(color: LuxeColors.outline, width: 0.5),
    ),
    color: LuxeColors.surfaceElevated, // nude-25
    shadowColor: LuxeColors.onSurface.withOpacity(0.04),
  ),

  // --- Input Theme ---
  inputDecorationTheme: InputDecorationTheme(
    filled: true,
    fillColor: LuxeColors.surfaceHover, // nude-75
    contentPadding: EdgeInsets.symmetric(
      horizontal: LuxeSpacing.space4, // 12px
      vertical: LuxeSpacing.space3,   // 8px
    ),
    border: OutlineInputBorder(
      borderRadius: BorderRadius.circular(LuxeRadius.md), // 12px
      borderSide: BorderSide(color: LuxeColors.outline, width: 1),
    ),
    focusedBorder: OutlineInputBorder(
      borderRadius: BorderRadius.circular(LuxeRadius.md),
      borderSide: BorderSide(color: LuxeColors.outlineFocus, width: 2),
    ),
  ),

  // --- Button Theme ---
  elevatedButtonTheme: ElevatedButtonThemeData(
    style: ElevatedButton.styleFrom(
      elevation: 0,
      backgroundColor: LuxeColors.primary,
      foregroundColor: LuxeColors.onPrimary,
      padding: EdgeInsets.symmetric(
        horizontal: LuxeSpacing.space5, // 16px
        vertical: LuxeSpacing.space3,   // 8px
      ),
      shape: RoundedRectangleBorder(
        borderRadius: BorderRadius.circular(LuxeRadius.full), // pill
      ),
      minimumSize: Size(0, 56),
    ),
  ),
);
