# 📝 Change Policy & Git Workflow

## Convención de Commits Estándar (Conventional Commits)
- `feat(domain): description` — Nuevas funcionalidades.
- `fix(domain): description` — Corrección de errores.
- `refactor(domain): description` — Mejoras de código sin cambiar comportamiento.
- `security(domain): description` — Correcciones de seguridad.
- `docs(domain): description` — Cambios en documentación.

## Reglas de Control de Cambios
- Los commits deben ser atómicos y lógicos.
- Cada cambio desplegable en Railway debe ser verificado por respuesta HTTP 200 OK.
