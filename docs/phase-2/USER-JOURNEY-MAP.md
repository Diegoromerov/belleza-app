# GLOWAPP PHASE 2 — USER JOURNEY MAPS

## 1. Client Core Journey (Discovery to Booking Completion)
`DISCOVERY` → `SERVICE SELECTION` → `PROVIDER SELECTION` → `AVAILABILITY (Cuándo/Dónde)` → `PRODUCTS/ADD-ONS` → `CHECKOUT/PAGO` → `CONFIRMATION` → `LIVE TRACKING` → `REVIEW`

## 2. Provider Core Journey (Onboarding to Service Execution)
`ONBOARDING` → `KYC SUBMISSION` → `SERVICE CONFIGURATION` → `AVAILABILITY SETTING` → `BOOKING RECEIPT` → `SERVICE EXECUTION` → `COMPLETION` → `PAYOUT`

## 3. Admin Core Journey (Operations & Resolution)
`LOGIN` → `OVERVIEW DASHBOARD` → `EXCEPTION ALERT` → `AUDIT INSPECTION` → `RESOLUTION ACTION` → `LOGGING`
