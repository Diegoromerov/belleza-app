# 🧩 Component Map — Sistema de Componentes & Design System

## 1. Componentes Globales de UI (`src/components/`)
- `Sidebar.tsx` — Navegación lateral adaptativa según el rol (`ADMIN`, `PRESTADOR`, `CLIENTE`).
- `Header.tsx` — Encabezado superior con avatar, estado del usuario y notificaciones.
- `ProtectedRoute.tsx` — HOC de protección de rutas y validación de sesiones JWT.

## 2. Paleta de Colores y Tokens Visuales (Tailwind CSS)
- **Primary Rose:** `rose-500` (`#F43F5E`), `rose-600` (`#E11D48`).
- **Dark Neutral:** `gray-900` (`#0F172A`), `slate-900`.
- **Background:** `gray-50` (`#F8FAFC`), `white`.
- **Status Green:** `emerald-500`, `emerald-50`.
