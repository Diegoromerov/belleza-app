# GLOWAPP PHASE 2 — CRITICAL FLOW UX AUDIT

## 1. Failure & Recovery UX Matrix
- **Payment Gateway Error:** Displays clear failure banner, preserves booking slot draft, provides immediate retry CTA.
- **KYC Document Rejection:** Displays explicit rejection reasons, highlight non-compliant fields, provides re-upload button.
- **Safety Incident Submission:** Displays immediate confirmation, provides emergency hotline numbers, issues ticket reference.
