# GLOWAPP PHASE 2 — PRODUCT UX BACKLOG

## 1. Strategic Backlog Structure
The Product UX Backlog prioritizes visual, interaction, and component updates required for Phase 2 functional domains.

---

## 2. Prioritized Epics & User Stories

### Epic 1: Design System Component Library Standardisation (P0)
- **UX-STORY-101:** Refactor all administrative dashboard buttons to use tokenized `Button` primitive.
- **UX-STORY-102:** Standardize form text inputs, select dropdowns, and textareas with unified focus ring styles.
- **UX-STORY-103:** Create reusable `Skeleton` loading components for dashboard metrics and client booking screens.

### Epic 2: Client Booking Flow Optimization (P0)
- **UX-STORY-201:** Implement 3-step wizard UI for client booking (Cuándo/Dónde -> Productos -> Pago).
- **UX-STORY-202:** Add sticky booking summary drawer for mobile viewports.
- **UX-STORY-203:** Integrate product cross-sell carousel in booking step 2.

### Epic 3: Admin Dashboard Responsive Layout (P1)
- **UX-STORY-301:** Enhance sidebar navigation collapse behavior on tablet screens (`md`).
- **UX-STORY-302:** Standardize metric cards (`StatCard`) across overview, analytics, and revenue screens.
- **UX-STORY-303:** Implement unified `DataTable` pagination and filter toolbar.
