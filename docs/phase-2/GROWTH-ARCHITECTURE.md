# GLOWAPP PHASE 2 — GROWTH ARCHITECTURE

## 1. Four-Pillar Growth Engine
1. **Acquisition:** Referral codes, social sharing, campaign landing pages.
2. **Activation:** Guided onboarding, first booking discount, provider first service incentive.
3. **Retention:** Reminders, rebooking prompts, favorite providers list.
4. **Revenue:** Promotions, service add-ons, cross-sell recommendation carousel.
