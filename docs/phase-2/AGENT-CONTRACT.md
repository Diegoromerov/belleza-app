# 📜 Agent Contract — Contrato de Ejecución Multiagente

## Reglas Contractuales para Agentes de Desarrollo
1. **Ownership Exclusivo:** Cada agente trabaja dentro de las carpetas asignadas a su GOAL.
2. **Archivos Prohibidos de Modificar Sin Autorización:**
   - `docs/phase-2/*` (Solo modificable en GOAL 00 o mediante RFC de gobernanza).
   - `admin-dashboard/tsconfig.json` y `next.config.ts`.
   - `backend/src/config/database.js`.
3. **Notificación de Dependencias:** Si un agente requiere un cambio en el contrato de API de otro dominio, debe documentar el cambio en un RFC antes de aplicar la modificación.
