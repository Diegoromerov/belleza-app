# GLOWAPP PHASE 2 — UX PRINCIPLES & GUIDELINES

## 1. Core Principles
1. **CLARITY:** Unambiguous visual hierarchy and actionable labels.
2. **CONSISTENCY:** Uniform colors, padding, button behaviors, and icon usage.
3. **LOW FRICTION:** Streamlined 3-step checkout sequence (1. Cuándo/Dónde -> 2. Productos -> 3. Pago).
4. **TRUST:** Clear status indicators, transparent pricing, and instant booking receipts.
5. **FEEDBACK:** Context-aware toast notifications, field inline validations, and skeleton loaders.
6. **ACCESSIBILITY:** WCAG 2.1 AA compliance, minimum 4.5:1 text contrast, 44x44px touch targets.
7. **MOBILE FIRST:** Responsive layouts optimized for single-handed touch interactions.
8. **PROGRESSIVE DISCLOSURE:** Complex configurations revealed step-by-step to prevent cognitive overload.
