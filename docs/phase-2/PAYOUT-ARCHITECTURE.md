# GLOWAPP PHASE 2 — PAYOUT ARCHITECTURE

## 1. Provider Payout Eligibility Rules
1. **KYC Verification:** Provider must be in `APPROVED` KYC state.
2. **Minimum Balance:** Available balance must satisfy minimum threshold ($50.00).
3. **Safety Holds:** Zero active `CRITICAL` or `HIGH` safety incidents or dispute holds on account.
4. **Bank Account Validation:** Verified bank account configuration.
