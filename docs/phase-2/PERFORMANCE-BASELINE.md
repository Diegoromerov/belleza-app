# ⏱️ Performance Baseline — Métricas de Rendimiento

## Métricas Baseline
- **Tiempo de Inicio del Servidor (Express):** < 1.2 segundos.
- **Latencia Promedio API REST:** 45ms a 120ms.
- **Conexión PostgreSQL Pool:** Max 30 conexiones activas.
- **Respuesta de Rutas Frontend (Next.js):** HTTP 200 OK con renderizado ISR / Client Side Hydration < 200ms.
