1. Procedimiento de Control de Información Documentada (Cláusula 7.5)

Establece las reglas para la creación, revisión, aprobación, codificación y actualización de todos los documentos y registros del SGC en GlowApp S.A.S.:

  • Codificación Estándar: Todos los documentos siguen la sintaxis `SGC-DOC-XXX` (donde XXX es el correlativo secuencial).
  • Aprobación Obligatoria: Todo cambio documental debe ser revisado por la Dirección de Operaciones y aprobado por el CEO/CTO.
  • Control de Versiones: Los cambios incrementales de forma menor se denominan v1.1, v1.2; mientras que revisiones de fondo modifican la versión a v2.0.

2. Procedimiento de Control de Cambios de Software & CI/CD (Cláusula 8.5.6)

Garantiza que cualquier actualización en la App móvil o panel administrativo sea probada previamente para prevenir caídas de servicio:

Flujo de Despliegue de Código a Producción

1. Pull Request (PR): El desarrollador crea el cambio en una rama aislada.
2. Pruebas QA: El Líder QA ejecuta pruebas automatizadas en ambiente Staging.
3. Aprobación CTO: Se verifica el Uptime y la compatibilidad con el Hub Biométrico y la IA.
4. Despliegue CI/CD: Despliegue automatizado sin caídas (Zero-Downtime Release).
5. Rollback Plan: En caso de falla crítica, se revierte automáticamente a la versión estable previa en menos de 5 minutos.
