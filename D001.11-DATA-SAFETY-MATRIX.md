- ✅ Safe / No change

- ❌ Error (should not happen with repairs)

### Summary of guarantees:
- No DROP TABLE or DROP COLUMN issued.
- No DELETE or TRUNCATE issued.
- No UPDATE that overwrites non‑NULL values.
- No INSERT that creates duplicate default tenant (ON CONFLICT DO NOTHING).
- All ALTER TABLE … ADD COLUMN are guarded by existence checks.
- All UPDATE are guarded by table/column existence and NULL check.
- All CREATE INDEX use IF NOT EXISTS.
- All ALTER TABLE … ENABLE ROW LEVEL SECURITY guarded by existence and current state check.
- All policy operations use DROP IF EXISTS CREATE.

Thus the repaired migrations are safe for re‑execution and will not cause data loss or schema corruption.
